
# RNF-007 — Disponibilidad del sistema

---

## Identificación

| Campo | Valor |
|:---|:---|
| **ID** | RNF-007 |
| **Nombre** | Disponibilidad del sistema |
| **Categoría** | Disponibilidad y confiabilidad |
| **Prioridad** | Alta |
| **Estado** | Por validar |

---

## Requisitos

### RNF-007.1 — Disponibilidad mínima

Hardwarex debe garantizar una disponibilidad mínima del 99 % durante el periodo de operación establecido.

### RNF-007.2 — Acceso a la plataforma

Los usuarios deben poder acceder a los módulos de equipos, mantenimientos, garantías y reportes cuando el sistema se encuentre disponible.

### RNF-007.3 — Recuperación del servicio

En caso de presentarse una interrupción, el sistema debe permitir recuperar su funcionamiento en el menor tiempo posible.

### RNF-007.4 — Monitoreo del servicio

Se debe realizar seguimiento al funcionamiento de la plataforma para identificar fallas o interrupciones.

### RNF-007.5 — Mantenimiento programado

Las actividades de mantenimiento del sistema deben planificarse para reducir las interrupciones del servicio.
