
# RNF-006 — Protección de los datos del usuario

---

| Campo | Valor |
|:---|:---|
| **ID** | RNF-006 |
| **Nombre** | Protección de los datos del usuario |
| **Categoría** | Seguridad y privacidad |
| **Prioridad** | Crítica |
| **Estado** | Por validar |

---

## Requisitos

### RNF-006.1 — Protección de información personal

Hardwarex debe proteger los datos personales de los usuarios, como nombres, correos electrónicos y demás información almacenada en la plataforma.

### RNF-006.2 — Transmisión segura

La información intercambiada entre el navegador y el servidor debe transmitirse mediante HTTPS utilizando protocolos TLS seguros.

### RNF-006.3 — Acceso restringido

Los datos de los usuarios solamente deben estar disponibles para las personas que cuenten con los permisos correspondientes.

### RNF-006.4 — Protección de información sensible

El sistema no debe exponer contraseñas, credenciales ni información privada en respuestas, registros o consultas no autorizadas.

### RNF-006.5 — Cumplimiento de seguridad

La plataforma debe aplicar medidas de seguridad informática y protección de datos personales de acuerdo con la normativa colombiana aplicable.
