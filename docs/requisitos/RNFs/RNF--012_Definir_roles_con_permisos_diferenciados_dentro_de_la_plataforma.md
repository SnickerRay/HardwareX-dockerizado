
# RNF-012 — Administración de roles y permisos

---

## Requisitos

### RNF-012.1 — Definición de roles

Hardwarex debe manejar tres roles principales: administrador, técnico y usuario.

### RNF-012.2 — Permisos del administrador

El administrador debe contar con permisos para gestionar usuarios, equipos, proveedores, garantías, solicitudes y mantenimientos.

### RNF-012.3 — Permisos del técnico

El técnico debe contar con permisos para consultar sus solicitudes asignadas, actualizar mantenimientos y registrar observaciones técnicas.

### RNF-012.4 — Permisos del usuario

El usuario debe contar con permisos para consultar información de los equipos autorizados y reportar fallas o solicitar mantenimientos.

### RNF-012.5 — Administración de permisos

El sistema debe permitir asignar y modificar los roles de los usuarios de acuerdo con las autorizaciones establecidas.

### RNF-012.6 — Separación de funciones

Los permisos de cada rol deben mantenerse diferenciados para evitar que los usuarios realicen actividades que no les corresponden.
