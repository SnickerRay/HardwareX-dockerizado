
# HU-TEC-006 — Visualizar la prioridad de las solicitudes asignadas

---

## Identificación

| Campo | Valor |
|:---|:---|
| **ID** | HU-TEC-006 |
| **Título** | Visualizar la prioridad de las solicitudes asignadas |
| **Módulo** | Gestión de mantenimientos |
| **Prioridad** | Media |
| **Estado** | Por validar |
| **RF asociados** | Pendiente de definir |

---

## Historia

Como técnico, necesito visualizar la prioridad de las solicitudes asignadas, con la finalidad de identificar cuáles requieren mayor atención y organizar adecuadamente las actividades de mantenimiento.

---

## Criterios de aceptación

**Pendientes de validación:** los siguientes criterios describen el comportamiento esperado de esta funcionalidad, pero requieren la definición y aprobación de un requisito funcional específico antes de considerarse establecidos.

### CA-TEC-006.1 — Visualización de prioridad

- **Dado que** existen solicitudes de mantenimiento asignadas al técnico.
- **Cuando** consulte el listado de solicitudes.
- **Entonces** el sistema debería mostrar el nivel de prioridad correspondiente a cada solicitud.

### CA-TEC-006.2 — Ordenamiento por prioridad

- **Dado que** existen solicitudes con diferentes niveles de prioridad.
- **Cuando** el técnico visualice el listado.
- **Entonces** el sistema debería permitir organizar las solicitudes de acuerdo con su nivel de prioridad.

### CA-TEC-006.3 — Identificación visual

- **Dado que** una solicitud tiene un nivel de prioridad determinado.
- **Cuando** el técnico consulte la solicitud.
- **Entonces** el sistema debería facilitar la identificación visual de su prioridad.

### CA-TEC-006.4 — Actualización de prioridad

- **Dado que** el nivel de prioridad de una solicitud ha sido modificado.
- **Cuando** el técnico consulte nuevamente el listado.
- **Entonces** el sistema debería mostrar el nivel de prioridad actualizado.

---

## Observación

Esta historia no tiene un requisito funcional asociado actualmente. Si se mantiene la gestión de prioridades dentro del alcance del proyecto, será necesario definir y aprobar un requisito funcional específico que establezca los niveles de prioridad y su comportamiento.
